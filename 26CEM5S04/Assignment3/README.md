## Aim
To classify astronomical objects using machine learning and compare SVM and Decision Tree classifiers.

## Dataset
**Star Classification Dataset (SDSS17)** containing astronomical observations classified into:
- GALAXY
- STAR
- QSO

## Methods Used
- Data preprocessing and standardization
- 2D t-SNE visualization
- SVM with Linear, Polynomial, and RBF kernels
- Decision Tree with different `max_depth` and `min_samples_split` settings

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- Execution Time
- Memory Usage

## Output Files
- `tsne_plot.png`
- `classification_results.csv`
- `class_distribution.csv`
- Confusion matrix images
- `26CEM5S04_ASSIGNMENT3.ipynb`

## Tools
Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn and PSUtil.

## Conclusion
The assignment demonstrates the application and comparison of SVM and Decision Tree machine learning methods for astronomical object classification.
